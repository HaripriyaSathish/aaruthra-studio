# Aaruthra Studio - Frontend (React + Vite)

Editorial South Indian Wedding & Heritage Photography Atelier Web Application.

## Highlights
- **Vite + React 19 + TypeScript + Tailwind CSS**: Lightning-fast dev experience on `localhost:5173`.
- **Editorial Typography**: Premium typography pairing (Cinzel, Cormorant Garamond, Plus Jakarta Sans) designed specifically for South Indian heritage weddings.
- **Interactive Features**:
  - Live wedding date & Muhurtham availability calendar modal
  - Comprehensive inquiry system with WhatsApp, Direct Phone, Email, and Google Maps integration
  - Interactive Admin Panel with live state management and Cloudinary sync preview
  - Curated photo archive with category filtering (Muhurtham, Couples, Rituals, Portraits)
  - Investment package selection and customizable quote estimator

## Running Locally

```bash
cd frontend
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.
